# Commit messages

Format: `<type>(<scope>): <summary>` — types `feat`, `fix`, `docs`, `refactor`, `test`, `chore`.

- Summary: imperative, ≤ 72 chars, no trailing period.
- Body (optional): *why*, not *what*; wrap at 72.
- Reference the ticket last: `Refs: PAY-123`.
